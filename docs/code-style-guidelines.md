# Code Style Guidelines

## Purpose

This document defines the coding conventions and engineering principles that should be followed when implementing, reviewing, or modifying code in this repository.

The goals are:

- maintain consistency across the codebase
- improve readability and maintainability
- prevent unnecessary complexity
- encourage framework and language best practices
- reduce architectural drift
- make code generated by humans and coding agents consistent

These guidelines complement framework documentation and project-specific architecture decisions.
They do not replace official framework behavior or project requirements.
Do not read unrelated technology guidelines.

- /code-style/TYPESCRIPT.md
